# LowerTale — Последний поезд

Релизная версия приключенческой игры на 30 глав. Главы открываются по мере прохождения. Управление, цели и сохранения описаны в [инструкции](app/README-RELEASE-RU.txt).

## Кооператив

Два игрока могут путешествовать по общей истории и сражаться с отдельными душами. Совместные испытания в первой комнате главы требуют действий обоих. Прогресс хранится на компьютере ведущего. Соединение прямое, без публичного сервера: через интернет потребуется проброс TCP-порта или общая VPN. Друг получает изображение с пониженной частотой кадров, но не звук. Оба игрока должны использовать версию 3.14.0. Инструкция по подключению — в файле релиза.

## Новое в 3.14.0

Исправлена карта после доставки главы, в том числе для старых завершённых заданий. Межглавный курьер сначала просит ввести вычисленный номер главы и лишь затем показывает локацию; времени теперь больше, а его запас зависит от сложности. Новые сцены, контуры, задания главы и испытания учитывают выбранную сложность; уже начатые головоломки сохраняют прежнее состояние и уровень.

Настольная версия уведомляет о новых релизах при запуске и затем примерно раз в 15 минут. В настройках можно включить автообновление: только специально отмеченные последовательные исправления скачиваются в фоне и устанавливаются после безопасного выхода и резервного копирования. Во время боя и испытания на время установка откладывается. Обновления с новыми возможностями устанавливаются вручную. Автообновление по умолчанию выключено. Сетевой доступ обязателен; в HTML-версии эта функция недоступна.

Перед переходом со старой версии экспортируйте сохранение. Новая версия перед обновлением создаёт резервную копию всех локальных слотов и настроек; восстановить её можно в меню сохранений. Состояние начатых сцен и контуров сохраняется. Активный бой после выхода начинается заново, а таймеры заданий продолжают идти даже при закрытой игре. В кооперативе прогресс записывается у ведущего.

## Поселения и боевое развитие

В первой комнате каждой главы житель предлагает побочное задание, а торговец продаёт оружие, броню и бинты за монеты. В кустах локаций 02–09 встречаются пять видов противников: победа и пощада дают одинаковые опыт и монеты. Каждый уровень добавляет 5 здоровья. В бою доступны силовой удар, контрстойка, парирование, рывок и защита. Боссы усилены; их мирные варианты сохранены. Во время испытаний и срочной доставки встречи не начинаются.

## Испытания на время

Каждый вид испытания приносит награду один раз в главе; неудачу можно повторить. Курьер доступен с третьей главы: межглавный маршрут предлагает вычислять номера открытых глав и искать метки в посещённых локациях. В настройках можно выбрать одну из трёх синтезированных мелодий, автоматический режим или выключить музыку.

Маршрут курьера рассчитывается по доступным проходам, а промежуточные метки добавляют секунды. На обычной и сложной у каждой метки свой сигнал фонаря L. Шифры стали быстрее, добавлена решаемая пульсовая сеть 4×4. Лимиты зависят от сложности; задания необязательны, неудачу можно повторить.

## Разнообразные цели глав

В 3.7 вместо одинакового требования пройти шесть сцен в каждой главе доступны пять типов основных заданий: восстановление, расследование, доставка на время, спасение и разведка. Штаб задания находится в первой комнате. Остальные сцены и контуры сохранены как дополнительные задания.

## Скачать

Готовые сборки для Windows и Linux находятся в [релизах](https://github.com/RUZIK558/LowerTale/releases). Выбирайте файлы без пометки TEST; они же продублированы с пометкой TEST для совместимости с обновлением версии 3.7. В настольной игре есть кнопка «Поиск обновлений»; обновление проверяется по SHA-256; автоматическая установка исправлений доступна по желанию после выхода.

## Запуск и сборка

Требуются Node.js и npm. Установите зависимости командой `npm install`; затем `npx electron app` запустит игру. Для сборки используйте `npm run build:windows` в Windows или `npm run build:linux` в Linux. Для HTML-версии откройте `app/index.html`; автоматическое обновление в браузере недоступно.

GitHub Actions собирает обе платформы и создаёт релиз при увеличении версии в `app/package.json`; если релиз этой версии уже существует, он не перезаписывается. Сборка зависит от доступности GitHub Actions и необходимых пакетов.

Лицензии шрифтов находятся в `app/licenses/`. Остальной проект: UNLICENSED; дополнительная лицензия не назначена.

Для разработчиков: только последовательный патч без новых возможностей допускается к автоустановке, если текст релиза содержит маркер `[LOWERTALE-UPDATE:BUGFIX]`. Минорные и другие обновления устанавливаются вручную.
