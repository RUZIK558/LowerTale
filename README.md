# LowerTale — Последний поезд

Тестовая версия приключенческой игры на 30 глав. Все главы и комнаты открыты, но задания в новой истории не пройдены. Управление, HUD и испытания описаны в [инструкции](app/README-TEST-3.6-RU.txt).

## Скачать

Готовые сборки для Windows и Linux находятся в [релизах](https://github.com/RUZIK558/LowerTale/releases). В настольной игре есть кнопка «Поиск обновлений»; обновление устанавливается только после подтверждения и проверки SHA-256.

## Запуск и сборка

Требуются Node.js и npm. Установите зависимости командой `npm install`; затем `npx electron app` запустит игру. Для сборки используйте `npm run build:windows` в Windows или `npm run build:linux` в Linux. Для HTML-версии откройте `app/index.html`; автоматическое обновление в браузере недоступно.

GitHub Actions собирает обе платформы и создаёт релиз при увеличении версии в `app/package.json`; если релиз этой версии уже существует, он не перезаписывается. Сборка зависит от доступности GitHub Actions и необходимых пакетов.

Лицензии шрифтов находятся в `app/licenses/`. Остальной проект: UNLICENSED; дополнительная лицензия не назначена.
