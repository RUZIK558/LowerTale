# Проверка LowerTale 3.4.0

- Автоматически проверены 70 новых контуров × 3 сложности: 210 вариантов.
- Для каждого варианта проверены генерация, допустимость сохранения, получение решения и состояние победы.
- Отрисованы все 70 контуров на сложной сложности без ошибок страницы.
- Заменено 18 наиболее формальных задач; у новых механизмов на сложной сложности проверенные решения занимают 8–52 действия, среднее 19,6.
- Проверено сохранение классического GUI: радиус основного окна 0 px.
- Это автоматическая функциональная проверка, а не полный ручной тест интересности, баланса и 7–10-часового прохождения.
- Windows-сборка проверяется структурно; запуск на реальной Windows в этой среде не выполняется.
